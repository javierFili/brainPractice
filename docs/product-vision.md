# Visión de producto

**BrainPractice** es una plataforma de práctica mental para cualquier edad: memoria, lógica,
atención, velocidad, patrones y razonamiento espacial, con la programación como especialización
opcional. Funciona como demo sin backend; toda la información se queda en el navegador.

## Promesa honesta

Practicar, explorar actividades variadas y observar el propio desempeño. **No** es un tratamiento,
no diagnostica, no promete prevenir el deterioro cognitivo, ni mejorar el IQ, ni que una mejora en
un juego se traslade a otras capacidades. Los resultados describen el desempeño en estas
actividades.

## Para quién

| Persona                                 | Qué encuentra                                                                    |
| --------------------------------------- | -------------------------------------------------------------------------------- |
| Alguien que quiere ejercitar la memoria | Ruta adultos/mayores, juegos de palabras, números, objetos y asociaciones        |
| Un niño                                 | Ruta niños: juegos visuales, instrucciones de una frase, sin presión de tiempo   |
| Un adolescente                          | Estrategia, lógica, retos visuales y récords personales (sin rankings)           |
| Un adulto con poco tiempo               | Sesiones rápidas de 3, 5, 10 o 15 minutos; reto diario                           |
| Una persona mayor                       | Texto grande, controles amplios, sin límites de tiempo, instrucciones repetibles |
| Un programador                          | 10 juegos de código, curso de lógica de programación, assessment específico      |
| Quien sólo quiere divertirse            | 60 juegos con 10 niveles cada uno                                                |

## Por qué volver (sin manipulación)

1. **Reto diario** reproducible (misma semilla para todos ese día); faltar un día no quita nada.
2. **Continuar** donde se dejó, con el siguiente paso explicado.
3. **Variedad**: recomendaciones de áreas poco practicadas.
4. **Progreso visible** y real: totales, récords por nivel, tendencias comparables, hitos.
5. **Metas voluntarias** (días por semana, minutos al día) sin castigos ni urgencias falsas.
